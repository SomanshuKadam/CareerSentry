# Workspace Instructions

## Hackathon source of truth

Before any CareerSentry hackathon research, planning, implementation, review, or recommendation, read `HACKATHON_PLAN.md` completely.

- Treat `HACKATHON_PLAN.md` as authoritative for scope, requirements, target selection, architecture, schemas, safety, and task status.
- If new evidence or a requested change conflicts with it, update `HACKATHON_PLAN.md` and its Decision log before changing code or other documentation.
- Do not silently add material assumptions. Record unresolved choices under `Open decisions`.
- After meaningful work, update the relevant checklist and evidence in `HACKATHON_PLAN.md`.
- Never commit credentials, API tokens, resumes, personal data, private job-search results, or `.env` files.
